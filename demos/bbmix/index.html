bbmix live demo

bbmix is a mixer for the RME Babyface Pro / Pro FS on Linux, written in Rust with egui. This is the real UI, compiled to WebAssembly and running in your browser.

loading bbmix…

How the web version works

  • The UI and mixer model are the same Rust as the desktop app, built for wasm32-unknown-unknown with eframe's web runner.
  • A browser can't reach ALSA, so it runs like bbmix --demo: everything works, but no interface is touched.
  • Your mix is kept in your browser's local storage instead of ~/.config/bbmix/state.json, so it's still there when you come back.
