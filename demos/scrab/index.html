Scrab live demo

Scrab is a file searcher written in Rust with egui. This is the real app, compiled to WebAssembly and running in your browser.

Searching a built-in sample file tree. Try rs, config or .png.

How the web version works

  • The UI and search code are the same Rust as the desktop app, built for wasm32-unknown-unknown with eframe's web runner.
  • A browser can't walk your disk, so the web build searches an in-memory list of paths instead of using walkdir.
  • If you pick a folder, only the file names are read. Nothing is uploaded and nothing leaves your browser.
