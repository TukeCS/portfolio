  • weather_shark

    A radar viewer for tracking tornadoes, written in Rust with egui. It decodes raw NEXRAD Level II data onto a chase map with roads and towns, splits into synced panes like a tiling window manager, and streams NOAA Weather Radio. It draws live NWS warnings and watches, with the full NWS text one click away, and SPC convective outlooks, and sounds an alarm for tornado warnings. Colours, layout and alert sounds, including your own, are all set in a Lua config.

    RustLuaeguiWebAssembly

  • bbmix

    A TotalMix-style mixer for the RME Babyface Pro / Pro FS on Linux, written in Rust with egui. RME never made Linux drivers, but the kernel exposes the Babyface's hardware mixer as ALSA controls, and bbmix is a front end for them: route every input and playback channel to any output, set preamp gain, 48V and pads, and link channels into stereo pairs. Your mix is saved and put back on the interface every time it connects.

    RusteguiALSAWebAssembly

    source live demo

  • trwm

    A dwm-inspired tiling window manager for X11, written from scratch in Rust. It has Hyprland-style spiral and dwindle split layouts alongside dwm's classic ones, plus a built-in status bar, screen locker and hot-reloading Lua config.
